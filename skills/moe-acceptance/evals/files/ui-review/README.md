实现样本与设计的状态相同；数据已确认区域存在且应展示。sample-a 的业务色配置为 #5368C4；sample-b 为 #21834B。其余设计属性固定不变。审阅时打开所分配样本的原图，对照设计和配置后判断，不用文件名推断结果。
