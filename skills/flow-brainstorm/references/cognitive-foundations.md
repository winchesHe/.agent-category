# 认知科学基础

理解人类思维的限制和机制，才能更好地辅助思考。这些不是直接给用户看的知识，而是指导你如何作为思维伙伴行动的底层依据。

---

## 1. 工作记忆限制与认知负荷

### 核心约束

人的工作记忆一次只能保持约 **4 个信息块（chunks）**。超过这个限制，思维质量急剧下降——这就是为什么复杂问题让人"头晕目眩"。

### 三种认知负荷

| 类型 | 来源 | 应对策略 |
|------|------|---------|
| **内在负荷** | 问题本身的复杂性（元素间的交互关系） | 分解问题、逐步处理 |
| **外在负荷** | 信息呈现方式造成的额外负担 | 改善组织、消除噪音 |
| **生成负荷** | 构建深层理解的有益认知投入 | 保持——这是有价值的 |

### 作为思维伙伴的启示

**当用户显得 overwhelmed 时，问题往往不是"想不通"而是"同时处理的东西太多"：**

- **分块（Chunking）**：帮用户把一团东西分成2-3个可独立处理的小组
- **外化（Offloading）**：把已经讨论过的内容总结成简短列表，释放工作记忆
- **分段处理（Sequencing）**：明确说"先不管B和C，我们就只看A"
- **降低外在负荷**：用简洁的语言和清晰的结构呈现信息，不要一次堆太多

**判断信号**：
- 用户开始重复自己说过的话 → 可能工作记忆已满，在刷新
- 用户说"等等，我迷失了" → 需要停下来做一次总结/外化
- 用户的回复越来越短/越来越含糊 → 认知疲劳，需要简化或休息

## 2. 认知固着与解法

### 什么是固着

大脑倾向于沿着已有的思维路径走——即使这条路径走不通。三种常见形态：

- **功能固着**：被事物的常规用途限制（锤子只能砸钉子）
- **设计固着**：被已有的范例/方案锁定（只能在现有方案上修补）
- **Einstellung 效应**：最近学到的解法占据搜索空间，阻碍发现更好的方案

### 为什么人会卡住

1. 外部信息（范例、已有方案）激活的记忆占据了注意力
2. 长期积累的领域知识反而缩窄了搜索空间
3. 人对自己进入了固着状态通常**不自知**

### 有效的破解策略

**对付外部信息导致的固着：**
- 孵化（暂离问题）— 让被误导的激活自然衰退
- 引入远域类比 — 激活不同的联想网络
- 改变抽象层次 — 从实现层上升到目的层

**对付内部知识导致的固着：**
- 表征变化 — 用不同方式重新描述问题
- 分解 — 把熟悉的整体拆成不熟悉的部分
- 约束注入 — 加入人工约束强制走新路径

**什么不管用：**
- 简单地说"不要被之前的方案影响" — 和"不要想白熊"效果一样
- 事先警告"你可能会有固着" — 人们不相信自己会犯这个错
- 只有在**经历了失败之后**，关于固着的指导才有效

### 作为思维伙伴的启示

当你判断用户可能处于固着状态时：
1. 不要直接说"你在固着"——用户通常不接受
2. 用行动而非诊断：引入一个远域类比、变换抽象层次、或引入新约束
3. 如果用户反复回到同一个方案同一个角度——这是固着的强信号
4. 建议暂离（"这个话题我们先放一放，回头再看？"）是合理的

## 3. 孵化效应

### 核心机制

搁置问题时大脑的无意识加工可能产生突破。Graham Wallas（1926）的创造过程四阶段：

**准备 → 孵化 → 顿悟 → 验证**

### 为什么暂离有效

1. **无意识加工** — 大脑在意识之外继续处理
2. **固着衰退** — 错误的路径从前景消退
3. **远程联想激活** — 大脑在休息时做更宽泛的联想搜索
4. **情绪重置** — 焦虑和挫败消退后思路更开阔

### 实用要点

- 长时间暂离 + 低认知负荷的填充活动 = 最大化孵化效果
- 孵化主要在人**被卡住之后**才有效——没卡住时暂离没什么特别效果
- 睡眠比普通休息的孵化效果更强（记忆巩固机制）
- 积极情绪促进创造性思维——情绪状态是实际杠杆

### 作为思维伙伴的启示

- 认识到"现在想不出来"不代表"想不出来"
- 适时建议暂离，特别是在经历了2-3次无进展的尝试后
- 在暂离前做好"状态保存"：总结当前进展、记录卡点，方便回来时继续
- 不要把暂离包装成放弃——而是"让无意识来帮忙"

## 4. 发散与收敛的神经科学

### 两种认知模式

| | 发散模式 | 收敛模式 |
|--|---------|---------|
| **特征** | 宽泛联想、跳跃、非线性 | 聚焦分析、线性、逻辑 |
| **适合** | 产生想法、发现可能性 | 评估想法、做出选择 |
| **需要的环境** | 放松、无压力、允许犯错 | 安静、聚焦、有标准 |
| **互相抑制** | 同时做两者 = 两者都做不好 | |

### 关键研究发现

- 发散阶段产生的想法数量和新颖性并不直接预测收敛阶段的结果质量（Frontiers, 2019）
- 真正影响最终产出的是**精加工过程（elaboration）**——把粗略想法发展成完整方案的能力
- 这意味着：发散后不能直接跳到"选一个最好的"，中间需要一个"发展/精加工"步骤

### 作为思维伙伴的启示

- **识别用户当前处于哪种模式**，不要在发散时强行收敛，也不要在收敛时引入新方向
- **标注模式切换**："现在我们切换一下，从产生想法转到评估想法"
- **保护发散**：在发散阶段压制批判冲动（无论是你的还是用户的）
- **中间加入精加工**：选出有潜力的想法后，先花时间发展它们再评估

## 5. 约束与创造力的倒U关系

### 核心发现（145项实证研究元分析）

```
创造力
  ↑
  |        ___
  |       /   \
  |      /     \
  |     /       \
  |    /         \
  |___/           \___
  +————————————————————→ 约束程度
  无约束    适度    过度
```

- 无约束 → 缺方向，反而减少产出
- 适度约束 → 聚焦注意力，激发在限制内创新
- 过度约束 → 窒息，无空间操作

### 约束的两种功能

1. **引导性（Directive）**：把注意力引向特定方向
2. **限制性（Limiting）**：缩窄可选路径

### 作为思维伙伴的启示

- 当用户面对空白页不知从何开始：**加约束**（"如果只能选一个方向呢？"）
- 当用户感觉被限制无法创新：**松约束**（"如果这些限制不存在呢？"）
- 约束是可以主动设计的工具，不仅仅是外部强加的条件
- 帮用户区分"真约束"和"假约束"——松掉假约束，利用真约束
